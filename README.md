# Toolbox

Small general-purpose toolbox container for Docker and Kubernetes.

Designed for:

- Shell scripts
- REST API calls
- JSON manipulation
- YAML manipulation
- DNS troubleshooting
- Network testing
- Kubernetes sidecars
- Kubernetes Jobs
- Init containers
- CI/CD automation

## Included tools

- bash
- curl
- wget
- jq
- yq
- git
- openssl
- ca-certificates
- envsubst
- dig
- nslookup
- ping
- nc
- grep
- sed
- awk
- find
- coreutils
- tar
- tzdata
